Methodology

Three checkouts of the same Swift codebase, identical except for doc-comment state:

  • Arm A — stripped: all /// and /** */ doc comments removed. 570 doc lines deleted across 52 files. Pure deletions; no code, formatting, or whitespace modified.
  • Arm B — skill-generated: Arm A's stripped baseline, then one full pass of the doc-comments skill. Generated 681 doc lines across 54 files.
  • Arm C — human-written (original): pristine origin/main. Hand-written doc comments by the codebase author.

Each arm received the identical task prompt below in 3 fresh, non-interactive claude -p sessions (stream-json output, --permission-mode bypassPermissions, fresh process per run, working tree reset between runs). 9 runs total. Same model, same prompt, no shared context.

Task prompt (locked)

Add a method to WatchlistManager called markAllEpisodesOfSeasonWatched(mediaId:seasonNumber:episodes:context:) that marks every episode in a given season as watched. After marking, it should trigger the appropriate notification rescheduling so that any pending notifications for those episodes are cancelled or updated. Follow the existing conventions for ModelContext handling, episode persistence, and notification side effects.

Metric: input tokens before first edit

"First edit" is defined as the first Claude tool call to Edit, Write, MultiEdit, or NotebookEdit. All input tokens (including cache reads and cache creation) consumed up to and including that turn are summed. This isolates discovery cost — the work the agent does before it knows enough to start acting.

Honest caveats

  • N = 3 per arm. 9 runs total. This is directional, not statistically significant. Variance within an arm is real and visible in the per-run tables.
  • One fixture, one task, one language. Results characterize this codebase and this task. They do not generalize without additional fixtures.
  • "First edit" is a proxy. It approximates the moment an agent has enough context to act. It does not capture quality of the resulting edit or downstream rework.
  • Same model for all arms. Opus 4.7. A weaker model would likely show larger deltas; a stronger model would show smaller ones.
  • The skill's own output is being measured against itself's premise. The skill was authored with this exact hypothesis in mind. The experiment falsifies or supports the premise; it does not prove the skill is optimal at producing the docs it produces.
